# Lithos — 3D Geological Crust & Magma Interactive Map

Interactive 3D geological stratigraphy and volcanic ridge visualization built with React 19, TypeScript, Three.js custom GLSL shaders, and Tailwind CSS.

## Features
- **Real-Time 3D Ridged Multifractal Rock Crust**: Custom GLSL vertex and fragment shader sculpting a diagonal basalt/metamorphic ridge with glowing molten magma fault veins and alpine moss/wildflower cursor illumination.
- **Interactive Crustal Cross-Section Slicer**: Peel back geological epochs from Holocene alpine tundra to Jurassic metamorphic beds and Hadean magma conduits.
